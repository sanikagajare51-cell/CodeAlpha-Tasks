# Student Management System

## Description
This is a simple Java console-based Student Management System project.

## Features
- Add Student
- View All Students
- Search Student by Roll Number
- Delete Student
- File Handling (Save data in file)

## Technologies Used
- Java
- OOP (Object Oriented Programming)
- File Handling
- Collections (ArrayList)

## How to Run
1. Open project in IntelliJ IDEA
2. Run Main.java file
3. Use console menu
